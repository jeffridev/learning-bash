# Learning Bash

Repositorio de aprendizaje de **Bash, terminal y scripting**.

## Objetivo

Desarrollar familiaridad con comandos de terminal y automatización básica mediante scripts.

## Temas de estudio

- Navegación y gestión de archivos
- Variables y parámetros
- Condicionales y bucles
- Scripts de automatización

## Estado

📚 En aprendizaje. Los temas son objetivos de estudio y no necesariamente funcionalidades ya implementadas.
